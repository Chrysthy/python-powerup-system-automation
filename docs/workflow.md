# Passo a passo do projeto

## Passo 1: Entrar no sistema da empresa
Acessar o sistema pelo navegador.

## Passo 2: Fazer login
Preencher o e-mail e a senha para acessar o sistema.

## Passo 3: Importar a base de produtos
Ler o arquivo com os produtos que serão cadastrados.

## Passo 4: Cadastrar os produtos
Preencher os campos do sistema com as informações de cada produto.

## Passo 5: Repetir o processo
Repetir o cadastro até que todos os produtos da base sejam inseridos no sistema.
