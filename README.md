# python-powerup-system-automation
Demonstração prática do uso de Python para automação de tarefas. Ele utiliza Python para criar um sistema que automatiza o cadastro de produtos em um sistema de empresa, utilizando bibliotecas como Pyautogui, Pandas e Keyboard. O sistema é capaz de abrir o sistema, ler a base de dados, e interromper a automação ao pressionar a tecla ESC.
